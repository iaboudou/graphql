## graphql

    GraphQL Project: A project built using the GraphQL query language to access and display user profile data from Zone01.


## Features

    - login Page
    - Profile Page
    - Graphs

## Usage
    - open [https://iaboudou.github.io/graphql/]
    - or clone the projet from github : [https://github.com/iaboudou/graphql.git]
    - Enter username/email and password.  
    - On successful login, access your profile data.
